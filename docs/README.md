# NewStim and RunExperiment manual

NewStim is a set of MATLAB routines for presenting visual stimuli using [Psychtoolbox](http://psychtoolbox.org/). RunExperiment is the graphical interface for configuring, transferring, and presenting NewStim scripts.

This documentation was ported from the Word manual last updated on 2021-03-10. The original file remains available as [Manual_ NewStim and RunExperiment.docx](<Documentation/Manual_ NewStim and RunExperiment.docx>).
