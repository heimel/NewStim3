# NewStim organization

[Back to manual index](README.md)

## Physical organization

NewStim is usually set up to run on two separate computers, the so-called local host and remote stimulus machines. The user will interact with the local host to select stimuli and to start the show. The remote stimulus computer will create and show the stimuli as ordered. This separate setup will ensure that the stimulus computer can concentrate completely on showing the stimulus and therefore no unwanted breaks will occur during the stimulus presentation.

## Stimulus organization

NewStim makes the distinction between a stimulus, e.g. a single drifting grating, and a script, which is a collection of stimuli, e.g. a series of drifting gratings with different directions. Any selection of stimuli can be merged into a script. Only scripts can be shown, but scripts can consist of a single stimulus.
